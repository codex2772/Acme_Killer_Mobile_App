---

## 🚀 Quick Start

## Prerequisites

Make sure the following are installed:

- Flutter SDK (3.x or higher)
- Dart SDK
- Android Studio / VS Code
- Android SDK
- Xcode (for iOS development)

Check installation:

```bash
flutter doctor
```

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_ORG/acme_killer_mobile_app.git
cd acme_killer_mobile_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```


## 📱 Build Application

Android APK
```
flutter build apk
```

Android App Bundle (Play Store)
```
flutter build appbundle
```

iOS Build
```
flutter build ios
```


# 🏗️ Project Structure

```
lib/
├── controllers/        # GetX Controllers (State management)
├── services/           # API services
├── models/             # Data models
├── views/              # UI screens
│   ├── home/
│   ├── product/
│   └── auth/
├── widgets/            # Reusable widgets
├── utils/              # Helpers & constants
└── main.dart           # App entry point
```

flutter test
